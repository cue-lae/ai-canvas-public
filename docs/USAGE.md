# 使用说明

目标为Windows x64，应用需要WebView2 Evergreen Runtime。请使用对应版本的安装器；源码目录不能直接当成已安装程序。安装和插件更新需用户分别执行，普通Canvas不依赖插件连接。

## 画布

导入图片后，可圈定矩形、椭圆或路径选区，用快速标注指出局部，用说明卡填写要求并关联选区。主动保存文档；多标签及窗口拆合、保存／另存为／重命名沿用既有入口。

Folder管理一组图片及说明。单击封面显示只读预览，双击封面或预览内容进入；聚焦封面按Enter也可进入。预览空白点击退出。管理操作使用封面右键菜单；键盘可用ContextMenu键或Shift+F10。预览中的内容保持只读。

画布缩放改变内容显示大小，系统DPI和应用控件尺寸是另一层设置。主题改变应用界面，不重绘图片本身。

## 复制与交接

复制图片会携带关联选区与快速标注；复制Folder包含其内部内容。跨图关联的说明需要一起选择相关对象，按画布提示补选。粘贴创建目标文档中的独立副本；说明输入框的文字粘贴不等同于往画布创建对象。

Codex Read主动交接当前画布；普通选择和编辑不表示上下文已发布。使用插件前按安装目录说明更新插件、确认版本并新建对话。只交接允许分享的图片和说明；局部视觉任务先选定允许修改的区域。
