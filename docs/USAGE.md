# 使用说明

## 安装与打开

目标为 Windows x64。使用经过确认的安装器，按界面选择安装位置；应用需要 WebView2 Evergreen Runtime。安装器、源码和工具依赖是不同交付物，源码目录本身不能直接当成已安装程序。

安装版启动说明见安装目录内「AI Canvas 安装说明」。插件使用还需在 Codex 中确认安装或更新，并新建对话；普通 Canvas 操作可以独立使用。

## 常用操作

1. 打开或新建画布，导入图片。
2. 用选区圈定范围；用快速标注指出局部；用说明卡写要求并关联需要说明的对象。
3. 用 Folder 管理一组内容。Folder 是内容容器，不等同于可以旋转的普通图片。
4. 按需要切换标签、拆出窗口或拖回其他窗口合并。
5. 主动保存文档；标签右键提供保存、另存为、重命名与关闭。

画布缩放改变内容的显示大小；应用工具栏和图标不应跟着画布内容一起缩小。应用界面主题统一，图片自身的颜色不由主题重绘。

## 跨标签复制

复制图片时保留它的选区和快速标注；复制整个 Folder 时包含其内部内容。无关联说明可以单独复制；说明关联到其他图片时，应一起选择关联内容，按照画布提示补选后复制。

粘贴生成的是目标文档的独立副本，不应修改源文档；整 Folder 的粘贴目标是主画布，不创建嵌套 Folder。说明输入框内的普通文字粘贴与往画布创建对象是不同操作。

## 与 Codex 交接

通过 Codex Read 主动交接当前画布，普通选择和编辑不等于已经发布上下文。请仅交接允许分享的图片与说明；局部图像任务应先选定允许修改的区域。

## 问题反馈

保存一份文档副本再重现问题；记录版本、动作顺序、是否跨标签/窗口、预期与实际结果。截图应移除个人资料，避免上传原始凭据或不允许公开的素材。
