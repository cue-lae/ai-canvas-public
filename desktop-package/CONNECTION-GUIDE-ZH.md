AI Canvas 安装说明
版本 {{PACKAGE_VERSION}} · 初版

一、安装或更新画布应用

1. 运行 AI Canvas 安装程序。首次安装可使用推荐位置，也可选择自己的应用文件夹。
2. 更新已有版本时沿用原安装位置，保留项目和设置；不要求先卸载。请先保存并关闭全部画布，并在 Codex 停用 AI Canvas 插件或旧画布读取连接。
3. 安装程序会同时准备 AI Canvas 插件并登记个人插件来源，不需要另解压插件或手工添加 MCP。
4. 完成后可打开画布。安装说明也可从开始菜单「AI Canvas 安装说明」打开。

二、在 Codex 中安装或更新插件

1. 完全退出再打开 Codex，进入插件目录，选择 Personal／个人来源；若该来源以前使用自定义名称，保留原名称。
2. 找到名称为「AI Canvas」、使用黑色 AC 图标的插件，确认安装或启用。第一次接入需要在 Codex 内确认一次。
3. 从原生读取试验版升级时，仍使用同一个插件身份。请在 Codex 中更新或重新安装该条插件，确认版本为 1.0.0，再新建对话；不要同时保留另一条手工画布 MCP 作为替代读取。
4. 无须运行单独的登记程序，也无须填写程序路径和参数。若找不到插件或更新失败，保留当前提示并回传，不要修改缓存或删除整个插件目录。

三、确认安装成功

在画布放入图片和说明，主动点击 Codex Read。然后在新的 Codex 对话启用 AI Canvas 插件，请它读取本次交接内容。应能读到新的图片和说明，并明确实际调用的插件读取工具。

连接可用不等于内容已交接；只有你点击 Codex Read，才会交接这次画布内容。打开画布自动准备后台连接，关闭最后一个画布窗口会自动结束连接。

四、局部图像处理

插件包含生成式和确定性两种工作方式。生成式使用当前 Codex 可用的生图能力；确定性依据明确颜色或参考进行处理。请说清想用哪种方式。两种都要求严格依据选区，检查选区外保持原样；结果写入新的图片，不覆盖原图。

插件本身不提供生图模型或账号额度。缺少生图工具、完整原图或精确选区信息时会明确说明，不能用猜测替代。具体执行规则由插件 Skill 引导，不需要你配置开发环境。

五、更新、停用与卸载

先保存并关闭画布，在 Codex 停用 AI Canvas 插件或旧读取连接，再运行更新或卸载。原试验版的数据位置保留，升级不强行搬移用户数据。

卸载仅清理确认归属的插件来源登记，保留用户另存项目、应用数据、插件源备份及其他插件。Codex 自己管理插件缓存；卸载后如仍显示已安装条目，可在 Codex 插件目录移除该条插件。

若检测到插件文件已被修改、同名来源冲突或其他应用的同名快捷方式，安装程序会停止而不是覆盖。请把错误提示回传，保留现场。
